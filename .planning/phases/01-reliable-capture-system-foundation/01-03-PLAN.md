## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TCC dialog → daemon capture paths | Grant state gates what the daemon may observe |
| launchd → daemon process | Restart semantics must not resurrect intentional stops or mask poison loops |
| /tmp log paths → user logs | World-writable log location is a symlink-attack surface |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | /tmp launchd log paths | medium | mitigate | Move logs to ~/Library/Logs/rustwatch/ (this plan) |
| T-03-02 | Denial of service | KeepAlive crash-loop storm | medium | mitigate | SuccessfulExit=false + ThrottleInterval 30 + D-04 no-loop classification from 01-01 |
| T-03-03 | Information disclosure | permission probing leaking state to logs | low | accept | Probe results are booleans/three-states only; no capture content in logs |
| T-03-04 | Elevation-adjacent | `stop` signalling wrong PID | high | mitigate | Implemented in 01-01 (probe + name-verify + poll); `doctor` verifies pid-file sanity here |
| T-03-05 | Denial of service | 30 s re-probe spamming TCC dialogs | medium | mitigate | Request-only-undetermined-once with persisted prompted_* flags; loop only checks (this plan, Pitfall 6) |
| T-03-SC | Tampering | npm/pip/cargo installs | high | mitigate | No fetches in this plan; new-crate STOP rule in the tracer task forces a checkpoint first |
